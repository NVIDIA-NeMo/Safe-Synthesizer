### 🔑 Choose where PII planning runs

Before training, NeMo Safe Synthesizer replaces personally identifiable information (PII), and an LLM decides which columns contain it. By default, NeMo Safe Synthesizer runs that LLM in a temporary vLLM server on this machine's GPU, so no API key is needed and the data stays on this machine. The local model needs an 80 GB GPU and downloads about 66 GB the first time it runs.

To use a hosted service instead, such as the NVIDIA API at `https://integrate.api.nvidia.com/v1`, set `NSS_INFERENCE_ENDPOINT`, `NSS_INFERENCE_MODEL`, and `NSS_INFERENCE_KEY` in the next cell. You can obtain an API key from [build.nvidia.com](https://build.nvidia.com/settings/api-keys). Column samples are then sent to that service. See [Where planning requests go](/user-guide/environment#where-planning-requests-go) for details.

### ⚙️ Create and run Safe Synthesizer job

Create the Safe Synthesizer builder and attach your DataFrame. Run the pipeline with `run()`, which performs data processing, PII replacement, training, generation, and evaluation in a single call. Results are available on `builder.results`.

Refer to the [configuration docs](/user-guide/configuration) for the full list of options.

```python
from nemo_safe_synthesizer.sdk.library_builder import SafeSynthesizer

ARTIFACT_ROOT = "safe-synthesizer-artifacts/safe-synthesizer-101"
builder = SafeSynthesizer(save_path=ARTIFACT_ROOT).with_data_source(df)  # .with_replace_pii(enable=False) to disable PII replacement
builder.run()
results = builder.results
```

```python
# View the evaluation report in a sandboxed iframe
import html
from IPython.display import display

report_html = results.evaluation_report_html
if report_html:
    # srcdoc, not a data: URL: Chrome blanks data: URLs over 2 MB, and the base keeps the report's #section links in the frame.
    report_doc = report_html.replace("<head>", '<head><base href="about:srcdoc">', 1)
    frame = (
        f'<iframe srcdoc="{html.escape(report_doc)}" sandbox="allow-scripts allow-popups" '
        'width="100%" height="800"></iframe>'
    )
    # Raw display: HTML() warns about a bare <iframe>, and IFrame() cannot take srcdoc.
    display({"text/html": frame}, raw=True)
```
